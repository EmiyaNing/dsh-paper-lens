# Best-Paper-Writing-Skill integration

This directory vendors the style-rules subset used by the Paper Lens "润色表达"
button.

- Upstream: https://github.com/gulucaptain/Best-Paper-Writing-Skill
- Version: v1.2 (commit b9eff99a2130bea960ef1050eacf9f40cb792dd4)
- License: CC BY 4.0 (see `LICENSE`), with the base-skill MIT notice in
  `LICENSE-base-skill` and `NOTICE.md`.
- `SKILL.md` and `references/style-rules.md` are copied unchanged for
  attribution and reference. `POLISH.md` is a narrow prompt adapter written for
  this plugin; it is not the upstream drafting workflow.

The exemplar bank, scripts, data and templates are **not** vendored: the
exemplars contain quoted paper text with separate copyright, and this plugin
only needs the paragraph-level style rules.
